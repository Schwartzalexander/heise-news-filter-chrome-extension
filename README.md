# heise-news-filter-chrome-extension

Chrome-Extension zum Ausblenden bestimmter Kategorien im heise-Newsticker.

## Funktionen

- filtert Newsticker-Einträge auf `heise.de` anhand der Kategorie im Meta-Bereich des Artikels
- konfigurierbar über das Popup der Extension
- blendet standardmäßig `bestenlisten` und `heise+ exklusiv` aus
- erkennt zusätzliche Kategorien beim Besuch der Seite automatisch und zeigt sie später im Popup an

## Installation zum Entwickeln

1. `chrome://extensions` öffnen.
2. Den Entwicklermodus aktivieren.
3. `Entpackte Erweiterung laden` auswählen.
4. Dieses Projektverzeichnis auswählen.
