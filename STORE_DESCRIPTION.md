# Chrome Web Store Beschreibung

## Kurzbeschreibung

Blendet unerwünschte Einträge im heise-Newsticker nach Kategorie oder regelmäßiger Rubrik aus.

## Beschreibung

Heise-News-Filter macht den heise-Newsticker übersichtlicher, indem ausgewählte Kategorien und wiederkehrende Rubriken direkt im Browser ausgeblendet werden. Die Erweiterung unterstützt den aktuellen Newsticker-DOM sowie Archiv-Teaser.

Die Filter lassen sich bequem über das Popup der Erweiterung ein- und ausschalten. Standardmäßig werden alle bekannten Kategorien außer `heise online` ausgeblendet. Weitere erkannte Kategorien werden automatisch in den Einstellungen angeboten, darunter auch `Alert`, `Angebot`, `Update` und `WTF`.

Zusätzlich werden regelmäßige Rubriken standardmäßig anhand ihres Titels ausgeblendet:

- Tageskurzzusammenfassungen mit `Montag:` bis `Sonntag:`
- `Missing Link:`
- `Zahlen, bitte:`
- `#TGIQF`
- `Post zum Freitag`
- `Kommentar:`

Die Erweiterung verändert keine Inhalte dauerhaft. Sie blendet passende Artikel nur lokal im Browser aus. Einstellungen werden mit Chrome-Sync gespeichert, sofern verfügbar.

## Datenschutz

Die Erweiterung arbeitet lokal im Browser auf `heise.de`. Es werden keine Nutzungsdaten gesammelt, keine Inhalte an externe Server übertragen und keine Tracking-Funktionen verwendet. Gespeichert werden ausschließlich die Filtereinstellungen der Erweiterung über `chrome.storage.sync`.
